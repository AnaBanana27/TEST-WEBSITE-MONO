## ✦ About the Project

**MONO** is a website for a design and development studio focused on creating unique, modern, and custom-built digital experiences.

The visual direction aims to communicate a minimal, sophisticated, and distinctive identity, avoiding generic templates and cookie-cutter solutions.

## 🚀 Features

* Custom UX/UI design
* Custom web development
* Minimal and modern design
* Subtle animations and interactions
* Responsive design
* Brand-focused digital experiences

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🎨 Concept

> Websites that don't feel like everything else.

MONO was created with the idea of building websites that don't just work, but have a personality of their own.
